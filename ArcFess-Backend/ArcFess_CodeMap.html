🗂️ 数据模型 Data Models

系统中流转的核心数据结构。Core data structures flowing through the system.

💾 Memory Entry (存储模型 — 后端 SQLite 表)

{
    rowid:         int64     // 自增主键 auto-increment primary key
    id:            string    // 客户端生成的全局唯一 ID (client-generated unique ID)
    text:          string    // 原始文本内容 original text content
    metadata:      JSON {    // 元数据 metadata
        taskId:         string    // 所属任务 ID
        type:           "chat" | "file" | "world_info"  // 来源类型
        chapter_title:  string    // 章节标题
        index:          number    // 在原始内容中的序号
        name:           string    // 角色名称
        uid:            string    // 内容哈希 (content hash for dedup)
        timestamp:      number    // Unix 毫秒时间戳
    }
    vector:        float32[]  // 嵌入向量 (BLOB 序列化存储) — serialized as BLOB
    timestamp:     float64    // 插入时间戳
    collection_id: string     // 所属集合 (e.g. "chat_abc_chapter_1")
}

📄 Content (内容模型 — 前端数据模型)

{
    id:       string           // 内容唯一 ID
    type:     "chat" | "file" | "world_info"  // 内容来源类型
    text:     string           // 文本内容
    metadata: { ... }          // 关联元数据
}

🔢 Vector (向量模型 — 嵌入结果)

{
    id:          string       // 向量唯一 ID
    contentId:   string       // 关联的 Content ID
    embedding:   float32[]    // 嵌入向量数组
    metadata:    { ... }      // 关联元数据
}

📋 Task (任务模型 — 向量化任务)

支持 Legacy (string ID) 和 New (object) 两种格式 — Supports both legacy and new formats:

// New format (current)
{
    id:            string       // e.g. "task_12345"
    name:          string       // 任务名称
    createdAt:     number       // 创建时间戳
    strategy:      "quota" | "boost"  // 注入策略
    strategyValue: number       // 策略参数值
    isExternal:    boolean      // 是否为外部任务
    sourceChatId:  string       // 来源聊天 ID
}

// Legacy format
"task_12345"  // 纯字符串 ID

🔄 ProcessingContext (处理上下文 — 管道状态容器)

{
    chatId:     string        // 当前聊天 ID
    settings:   object        // 扩展设置快照
    metadata:   object        // 聊天元数据引用
    timing: {                  // 计时数据
        start:    number       // 处理开始时间
        end:      number       // 处理结束时间
        duration: number       // 总耗时 (ms)
    }
    state:      object        // 处理状态跟踪
    data:       object        // 累积数据 (逐阶段附加)
    errors:     []            // 错误收集
    warnings:   []            // 警告收集
}
